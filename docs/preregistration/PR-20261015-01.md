# PR-20261015-01：B的ACT固定场景基线收束与最终测试

日期：2026-10-15。授权：用户明确要求“直接把当前B的ACT基线收束并作最终测试”，不再要求当前ACT基线具有较强泛化能力。该决定替代本次拟议的8次新位置开发测试，允许立即冻结并最终测试当前B-ACT版本。

本修订只改变当前B-ACT的测试范围和执行时点：使用既有两个布局、两种物体、原取物标记、固定相机与目标左右半区的新执行回合。它不采用原协议final test的“新物体/新位置/新场景/新语言”矩阵，结果只支持熟悉条件下的基线表现。当前B-ACT收束不等同于整个项目、sim2real、SmolVLA或动作结果模型工作完成。

冻结规则、测试顺序、成功语义与统计方式在控制机测试目录的[PROTOCOL.md](../../artifacts/b-act-final-fixed-20261015/PROTOCOL.md)中明确：四技能×两布局×各5个计分回合，共40个固定编号；每次最多60秒，固定种子20261015生成顺序，前20次布局1、后20次布局2；用户追加要求以单命令session逐回合推进，每回合仍由操作者确认复位、启动并标注结果。

成功要求正确物体完整释放于正确半区内部且未压线，观察稳定2秒，无人工接管或保护拒绝。操作者选1成功或2失败即保存；仅选3外部操作/摆放无效时填写原因。40个固定编号各产生一个计分结果；误松LB、错误复位等外部无效尝试保留原动作、图像、日志和标签，同一编号使用独立retests目录重测。策略失败、保护拒绝、人工接管、超时及相机/通信/程序/保持故障均计失败，不作为无效排除。开始前取消不创建尝试，缺失结果保持未闭合；安全故障可暂停批次，改变冻结条件的修复必须另建版本并保留旧结果。

报告每格成功率与95% Wilson区间，总体8格等权，完整40回合时等于总成功/40；同时列外部无效尝试及原因、实际尝试数、程序自动记录的错误/保护拒绝、原始动作/RGB索引与执行时序。没有预设必须达到的成功率门槛，不因最终分数不理想再换checkpoint、训练或筛除失败。

上述外部无效重测规则由用户在第1编号仅有一次误松LB、尚无计分结果时明确加入（入口修订4）；随后用户要求成功/失败直接保存，取消首次抓稳与失败备注追问（修订5）。旧入口、协议和freeze保留在控制机preparation-history；四模型、控制源码、数值配置、顺序及完整成功判据保持。修订5部署时为0个计分结果、2个外部无效尝试，见[部署状态](../../artifacts/b-act-final-fixed-20261015/evidence/deployment-revision5/status.json)。
