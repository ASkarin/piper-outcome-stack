## 2. A → B → C 的范围

A近期继续绿色方块四起点抓放，先完成已批准20次尝试的清单/审计与最小ACT训练、受监督实机闭环。20次尝试不等于20条成功示范，失败单独保留；硬件诊断回合不自动纳入训练。之后再以杯子、开放容器扩展A/B，不替换已采记录。

B使用有区别的物体和目标指令。同一布局支持不同正确指令，物体/起点/目标不形成固定捷径；语言改写不能冒充新增机器人经验。具体模板、左右参照系、对象实例与组合划分在B正式采集前冻结。

C首版包括固定抽屉、限定物体集合与摆放范围、文本指令选物、打开抽屉、抓取放入并释放、关闭抽屉，以及漏抓／抓取前目标移位后的有限恢复。语音、变化障碍布局下的规划避障、放下重抓及空中重抓不纳入首版承诺。现有工具点间隙与IK检查不等于连杆、夹爪、所持物体的避障能力。

10月4日同时核对：安全采集链路已有依据；A有可重复ACT基线；把手、拉开空间、杯子容纳与关闭、关键过程可观察；剩余容量不挤占ACT、S3核心迁移、结果模型和冻结评测。通过后冻结C细则并开展正式采集；未通过只作探索/展示，不影响最低成功标准。

## 3. C的成功、恢复与对照

完整成功：在冻结总时限和恢复预算内，将指令对应物体放入抽屉、完全释放并完成关闭；无人工接管、策略导致的故障锁存或越界动作。阶段完成依据真实观测，不能只凭命令发出或固定计时切换。

同一操作技能与恢复动作集合下设置三组：无恢复、规则检测与恢复、结果模型指导恢复。共同固定场景、扰动、随机化顺序、总时间和最大尝试预算；无恢复组不使用恢复机会，另外两组使用相同恢复权限。分别报告首次完整成功率、预算内完整成功率、恢复成功率及分母、错误介入、阶段失败、接管和完成时间。二元指标保留Wilson区间，差值保留冻结的分层bootstrap规则。

仅对已定义任务失败允许有限恢复。CAN/SDK错误、过期反馈、watchdog、FAULT/E_STOP仍按既有停止规则结束，不自动reset/enable或继续。结果模型只能建议现有合法技能，不能绕过动作验证。恢复策略本身需要示范与验证，检测能力不等于恢复能力。

C的物体/抽屉、开闭与稳定判据、阶段标签、扰动时机、最大恢复次数、总时限、示范量、seed及各组评测预算须在启动条件通过后、正式采集/实验前另建带具体值的冻结修订。旧100—150条不再作为自动额度；本文件不预填未经可行性测量的数值，也不授权现在运行C。

## 4. 模型与数据准备

标准ACT没有原生语言输入。B默认比较“受限指令解析→选择ACT技能”与语言条件SmolVLA，是系统级比较；报告解析错误、技能数量、合计训练成本以及端到端结果，不称ACT原生理解自然语言。共享原始输入、可比示范预算与划分，预训练和各自预处理成本单列。

SmolVLA从机器人预训练checkpoint微调，记录精确revision、七维动作/图像/语言适配及实际可训练参数。只加载VLM后训练动作头不等同于上述微调。内部VLM不随意替换；独立高层VLM暂不新增，是否需要由B的开发证据决定。中文与任务文本转换如被采用，须显式记录并单独评估。

当前Xbox任务文本来自会话dataset.single_task；start P1/P2是起点标签，不切换语言任务。不同指令目前用明确任务配置分别开会话，逐回合切换文本或恢复片段标注尚未实现。

成功且有效的完整回合用于现有行为克隆选择；失败原始记录用于诊断/结果模型。恢复训练须另行明确有效阶段及片段，不能因最终成功而把此前错误动作全当正确监督。源轨迹、完整回合、裁剪/去停顿派生版本同组划分，不能跨train/development/validation/final test泄漏。

## 5. 已实现的数据与控制契约

- Xbox：同一行保存新图像、状态和实际发送/已确认保持目标，N个有效原始帧生成N行；SDK起止/结果真实保留。准备与A/Y不入示范，正常暂停帧保留。
- 示教：只接收入口不发控制命令；连续有效N帧生成N−1行，关节action来自下一帧，夹爪采用已批准的max(0,下一帧原始宽度)。原始有符号观测不改写，映射逐行记录并复查实际编码目标；不是对任意执行动作的裁剪许可。
- Xbox控制线程校验、复制、入队；后台有界写入并保留同步步骤。save只封存原始回合；压缩/视频编码和官方Dataset创建、finalize、reload及来源审计在离线转换完成。示教保存行为独立，不据此改写。
- 停顿先检测、人工确认后导出独立版本；图像/状态/action同行处理，记录真实来源及时间间隔，不插值补帧或改写原始记录。
- 默认Xbox控制与Dataset50Hz、相机640×480 RGBD60；RGBD采集不等于策略消费深度。历史20Hz与当前50Hz、Xbox与示教不自动混合；action chunk与时域比较须注明帧数和秒数，不能直接照搬旧频率下的时长解释。
- X默认腕部优先保持平移，允许朝向随动；固定腕部的J1–J3位置求解失败后使用腕部高权重六轴位置求解，共享IK预算。X另一策略保持朝向，RB姿态模式绕105mm抓取中心；135mm指尖模型仍用于间隙检查。六维奇异判据不套用于纯位置任务。
- A/Y保持阶段分批验证完整路径，执行前核对新鲜起点，LB取消/B优先；夹爪按时间推进并仅提交有效下发参考。不改变七维动作、不自动放宽限位或反馈期限。
