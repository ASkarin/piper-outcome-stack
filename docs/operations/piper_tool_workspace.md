# 工具点工作区与桌面检查

## 当前含义

工作区仍由同一Robot/IK路径执行。安全配置新增可选的 `workspace_geometry`；未提供时沿用现有法兰XYZ方框语义，提供时三个边界分量分别表示：指尖中点基座X、基座Y、相对桌面的法向高度。不能把两种坐标混填。

几何项包含 `tip_offset_m`、`grasp_offset_m`、`opening_axis`、`table_normal`、`table_offset_m`。偏移和开合轴位于法兰局部坐标系，法向量位于基座坐标系；平面为normal·position=offset，单位米。当前指尖偏移135mm、内部抓取中心105mm；开合轴依据标准夹爪模型取法兰Y轴。

每次检查使用实际姿态旋转这些点。检查TCP的X/Y/高度范围，同时检查理想两指末端、抓取中心与法兰点是否高于最低间隙；上限高度仅作用于TCP。这里没有壳体/手指厚度、被夹物体、臂体、自碰撞或连续扫掠体模型，不是完整碰撞检测。

## 统一调用路径

- Xbox的目标位姿、实际关节航点、A/Y预计算路线、Robot发送前和示教转换使用同一几何函数。
- 单独开合夹爪也检查两指高度。SDK关节调用返回不代表已抬起，因此同时抬臂/张爪时，开合必须在当前姿态也合法。
- 允许受监督向内退回，但任何已越界的检查分量都不能进一步恶化。固定臂体的夹爪动作只检查它改变的两指高度，不把不变的XY位置变成新的恢复障碍。
- 测得的小负开口保留原值，在理想对称点模型中只交换两指标签；负的指令目标仍由既有范围检查拒绝，不裁剪为零。
- 七维rad/m动作、法兰IK目标、暂停/B急停、反馈与步长检查保持原有接口。配置和处理器序列化保留完整几何参数，动作遥测附带检查坐标。
