# 新场地配置与采集

更新：2026-09-21。已有基本功能不重复验收；底座、相机视角、工具或取放区改变时只复核受影响部分。独立30分钟/20安全回合和release不是日常采集前置；实时反馈、模式、动作/间隙和数据质量检查保留。

## 当前场地与新模板

已有场地使用活动operator/profile.json、record.json与safety.json，不用模板覆盖。默认piper record为控制/Dataset50Hz、640×480 RGBD60，新的原始数据与转换输出进入SSD的xbox-50hz目录。

新场地从configs/scenes/new-table模板复制到独立目录，补充scene_id、实际安装/视角、工作区、相机身份与测得的时间参数。A/X映射按设备实测；模板候选工作姿态不是新桌面的安全结论。当前软件0～120mm夹爪目标、1N、15mm相对反馈上限及SDK50%/关节10°是已批准活动配置，不等于120mm物理行程或任意安装均安全。

内部抓取中心偏移105mm，指尖检查偏移135mm；姿态影响两指最低位置。现有8mm工具间隙有约9mm几何偏差，不等于实体/扫掠体/持物避障。已有相机到基座外参在安装变化后需重新核对；没有外参不自动阻挡人工RGB遥操作。

## A/Y与手柄

新设备仅用xbox-input测按钮，不猜索引；已实测且设备未变不重复测量。X切换腕部优先保持/保持朝向平移，RB选择姿态，全部摇杆/扳机都参与回中。

A/Y请求时LB松开、保持确认、全回中；松开目标键后按住LB。完整路径在保持循环分批检查，提示规划中时可继续按住等待，松LB取消且不排队。起点变化明确拒绝，不用旧规划直接发令。只有终点连续反馈确认才报告到位；中间参考按时间与反馈推进。B优先，到位暂停并保留使能。

## 搬迁影响的时间核对

新设备/流或USB拓扑改变时，按明确read_only配置做联合测量，先暖机再测60秒；当前模板为640×480 RGBD60、采样50Hz：

```bash
sudo piper-socketcan exec -- /实际开发目录/.venv/bin/piper-outcome-stack capture-timing measure   --config /实际新场地/measure.json --output /实际新场地/timing-01 --seconds 60 --fps 50
```

实际相机流可以高于Dataset频率。接收时间、设备域、帧龄、反馈组偏差、图像—状态偏差和处理耗时分别记录，不宣称曝光硬同步。时间配置由现场测量与操作者确认，不能为掩盖长周期放宽。基础硬件身份和已完成能力不重复设置验收文件gate。

## 原始封存与离线转换

在已配置的控制机用piper record。准备动作/A/Y不入数据；start P1开始，end结束，save success/failure/cancelled封存，保存完成可直接start P2。redo保留弃用attempt。额度20不是已完成20次成功，起点次数由实际清单核对。

控制线程只校验、复制、入队；后台有界写入并保留fsync。save等待完整落盘，不在控制循环做压缩/编码。退出后按Session目录运行piper convert、piper audit；官方Dataset创建/finalize/reload在离线阶段。停顿候选由piper pauses生成，人工确认后才导出独立版本；原始数据保留。

当前优先绿色方块四起点A闭环。B后续增加杯子/容器与真实不同文本；single_task是会话文本，start P1/P2不切换语言。C抽屉任务须按[PR-20260921-01](../preregistration/PR-20260921-01.md)通过10-04启动条件；不据本说明启动新技能、模型或硬件。
