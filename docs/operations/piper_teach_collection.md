# 拖动示教：原始录制、离线转换与审计

2026-09-21说明：默认Xbox已50Hz／RGBD60，本文独立示教模板/历史会话不随之改频率。Xbox N行实际目标与示教N−1候选目标不自动混训；成功有效回合、失败记录和未来恢复片段分开。最新研究方向见[PR-20260921-01](../preregistration/PR-20260921-01.md)，本入口尚无C恢复控制。

Xbox 保留原有六维遥操作、夹爪、LB保持、B急停和A/Y姿态功能。`teach-record` 是另一种采集来源，不是另一个控制后端；使用同一官方SDK接收器和RealSense实现。每次只运行一种硬件会话。

## 确认后返回工作姿态的连续采集

`teach-collect` 复用原始录制与保存流程，并在回合之间提供准备运动。它不是全程只接收：只有输入 `prepare` 明确确认后才切换到运动会话。首次准备或主动选择回工作姿态时，先结束机械臂示教、手离开，再输入 `prepare`。保存/重录后可直接start下一点。仍在示教录制时会拒绝移动。

到位后手动切入示教，输入 `start P1` 开始；完成任务后输入 `end`、`save success` 或 `save failure [备注]`。保存完成可直接 `start P2` 从当前位置继续，或选择 `prepare` 回工作姿态后开始。`cancel` 留在确认阶段，`quit` 退出；准备运动中 `stop` 取消并确认保持，Ctrl+C 请求电子急停（可能下沉）。录制/保存期间仍只接收反馈，Ctrl+C 不会停止机械臂，Xbox按键不参与此入口。

准备阶段只发送六轴位置目标，不发送夹爪位置、夹爪使能或力参数。这样不会用示教测得宽度覆盖原夹爪指令；模式切换时真实夹持行为仍需现场验证。准备时关闭只接收SDK连接，运动结束后关闭运动连接，再重新打开只接收连接，两者不同时占用CAN。相机在切换后重新暖机。

在示教配置顶层添加 `preparation`：`work_joint_rad` 为六个弧度值，`safety_path` 指向本场地安全配置，`hold_settings` 包含已测的 `joint_tolerance_rad`、`stable_time_s` 和 `timeout_s`。运行：

```bash
sudo piper-socketcan exec -- "<editable目录>"/.venv/bin/piper-outcome-stack teach-collect \
  --config "<连续示教配置.json>" --output "<新原始目录>"
```

准备动作写入独立 `preparation-*` 报告，不进入示范帧。原始回合仍是实际RGB(D)/关节/夹爪反馈，转换规则仍为下一帧实测状态生成动作。准备结束与切入示教后可能有姿态变化，回放起点以实际首帧为准。`teach-record` 继续保持原有全程只接收契约，并拒绝含准备运动配置的调用。

## 只接收边界

`teach-record`支持RGB或RGBD，不创建运动Robot或Xbox输入实例，不发送使能、失能、模式、夹爪、急停、恢复或位置指令；SDK发送函数在本会话被拦截。**Xbox B在这个入口不生效，结束采样不会停止或改变机械臂。** 操作者按机械臂示教按钮进入/结束示教，不双击回放。是否使能不能单独判断是否可手动拖动，以当前控制模式和真实操作为准。

本机没有抱闸，失能、电子急停或断电可能下落；软件不会自动切换这些状态。程序要求新鲜完整反馈和示教状态，拒绝其他模式，不自动修复、重连或查询角色。示教内存轨迹可能被新的按钮录制覆盖；电脑上的原始回合独立保存。

## 配置及操作

复制 `configs/teach-record.template.json` 并填入当前已确认配置。四项capture_timing和feedback_timeout不猜测默认值；使用本场地已测值。camera名字和设备配置可调整，日常调试该独立示教模板为D435 RGB 1280×720、30fps，采样20Hz；重要示范通过`use_depth=true`保留RGBD。scene必须描述当前安装，换桌后另建配置和原始目录。

控制机管理员在交互终端执行（替换尖括号内容）：

```bash
sudo piper-socketcan exec -- "<editable目录>"/.venv/bin/piper-outcome-stack teach-record \
  --config "<示教配置.json>" --output "<新的原始记录目录>"
```

控制台只显示阶段、操作提示和异常。准备完成后：

1. `start debug1`：准备一个回合；已在示教录制则直接采样，否则按提示单击机械臂示教按钮。
2. 手动拖动臂体、开合夹爪。`end` 或停止按钮示教均正常结束；到达配置时长也结束采样。按终端end或时长结束不会自动关闭示教。
3. `save success`、`save failure 备注` 或 `save cancelled 备注` 保存；任务成功与数据有效性分开。`redo`保留弃用证据，随后重新输入start；`quit`放弃未保存回合并退出，已保存回合保留。
4. 保存期间不接收下一次操作；等待提示返回准备阶段。结束时确认机械臂示教录制已由操作者停止。

`--resume`仅允许原始会话配置完全一致时追加新attempt，不继续一个中断的回合，也不改变或晋升旧失败记录。没有两帧不能生成下一帧目标。数据文件写入或压缩失败、重复/过期图像、缺失反馈、采样跳周期、时钟异常会使当前attempt无效，已落盘证据保留。原始图像与Z16快速暂存；保存时对深度做无损压缩并逐文件验证。

每次连接记录解释器、命令、源码基线/diff及运行源码副本。原始session包含scene和完整配置，每个attempt保存samples、RGB、任务结果及配置启用时的Z16。图像设备时间与主机接收时间分别保存，不宣称硬件同步。名义20Hz索引不是精确曝光时刻，以逐行时间戳与分位数报告判断实际质量。

## 离线转换

结束硬件会话后，在有固定LeRobot及pyAgxArm运动学依赖的环境执行，**不需要sudo，不连接设备**：

```bash
piper-outcome-stack teach-convert --source "<原始记录目录>" \
  --output "<全新的Dataset目录>" --repo-id local/teach-pilot \
  --safety "<当前执行限位配置.json>"
piper-outcome-stack audit-dataset --root "<Dataset目录>" --repo-id local/teach-pilot
```

默认用官方RGB视频编码；`--no-video`保存RGB图像。默认只导出RGB、状态和动作；`--include-depth`才从原始Z16生成米制TIFF。未采集深度的会话不能补造深度。转换输出与原始目录独立，已存在的输出不覆盖；需要改变规则或参数时指定另一个新目录，不续写/混入Xbox Dataset。

当前规则为 `next_observed_state_gripper_nonnegative_v2`：observation[t]保持原始第t帧，action[t]的关节来自第t+1帧，夹爪为max(0,下一帧原始宽度)。旧v1只用于原有Dataset审计。N帧生成N−1行；末帧保留在证据中，不凭空生成动作。七维顺序沿用joint_1.pos至joint_6.pos、gripper.pos，单位rad/m。原始样本不含action字段。

转换索引记录原始attempt、观测与目标来源帧、实际时间间隔；SDK调用起止和结果为空，不能把派生动作说成已经下发或到位。只转换saved/data_valid回合，失败和弃用attempt仍留在原始目录。转换检查目标关节/夹爪限位、相邻增量及官方MDH/工具点工作区；失败明确报出attempt和帧号，不裁剪、不平滑、不放宽参数。手动示教可到达当前执行配置之外的位置，这样的记录仍能保存，但不能按该配置转换为候选动作。

Dataset保留数值/RGB来源证据、索引与转换状态，不复制Z16；完整原始会话是唯一深度归档。默认RGB导出可独立审计。显式深度导出审计须保留原始归档，迁移后使用`audit-dataset --root <Dataset> --repo-id <id> --raw-source <原始归档新位置>`明确路径。审计核对状态、下一帧动作、RGB/视频可加载及每回合N−1关系；导出深度时再与原始Z16核对数值。Xbox审计仍只接受实际下发或合法保持动作；Xbox不能续录示教Dataset。训练输入仍由既有配置选择，默认RGB和七维状态；时间与模式不进入策略向量。

## 当前现场进度与下一步

2026-09-10只读可行性试验确认拖动时能读取关节及RGBD；夹爪试验`run-20260910T141245Z-A3sZIL`保存87组、约8.6秒，宽度0→50.6→约1.1mm。旧诊断脚本把提前停止归为异常；原失败报告保留，不改写成完整10秒验收。

新20Hz流程需由操作者验证一条短抓放尝试，检查手对指尖/物体接触区的遮挡、夹爪反馈、时序和保存。失败也保留，不凑成功数。旧桌面数据是开发试采集；换桌后的场地参数与首批4起点×5次计划不变。

成功转换不等于ACT可用或实机回放通过。下一帧目标是候选训练语义，其跟踪效果、手遮挡域差异和执行平稳性仍待后续验证。Xbox执行抖动问题仍保留。本轮不训练、不自动回放、不改正式release。

### 保存后直接继续（2026-09-14）

首次启动仍需 prepare。保存或 redo 后可输入 start P2（重录则原编号）直接开始，或选择 prepare 回工作姿态。示教尚在录制状态时无需再次按按钮；start 不发送使能、失能或模式命令。prepare 被拒绝或未到位时须先完成准备，不自动跳过。

相机正常连接/断开信息写入运行日志，控制台保留异常。start 到示教反馈确认的等待时间会记录，包含人工按按钮的时间，不等于驱动释放延迟。

### 示教 action 的闭合目标规则（2026-09-14）

新转换使用 next_observed_state_gripper_nonnegative_v2：关节 action 为下一帧原值，夹爪 action 为 max(0, 下一帧原始宽度)；observation 保持原始有符号反馈。原始 RGBD 和数值记录不改写。逐行保存原始下一宽度、实际编码目标、是否映射，并汇总受影响帧数及原始最小值。映射不宣称负反馈正常，也不将静摩擦闭合读数当作零点标定。

按转换后的实际 float32 目标重新检查夹爪上限、步长、关节和工具间隙；不放宽工作区。已有 v1 Dataset 按原身份规则严格审计，不改写历史文件。新转换不提供旧行为配置开关。Xbox 下发与动作审计不变。

### 选择本次转换的起点

`teach-convert` 默认处理全部已保存回合。若审阅后需要将部分起点单独导出，可重复指定 `--position`，例如 `--position P2 --position P3 --position P4`。选择会写入转换记录并参与审计；所选起点的全部已保存尝试都会处理。未选记录、失败和弃用记录保留原状，不通过修改原始状态来排除数据。所选起点不存在已保存回合时明确报错。
