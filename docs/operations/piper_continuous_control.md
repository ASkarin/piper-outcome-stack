## 摇杆

`streaming_reference` 指定 `period_s`、`ramp_time_s`、`lead_cycles`。输入先变成期望末端速度，再以有界的真实 dt 生成连续参考；参考领先反馈过多时缩小或冻结进度，不积累待补动作。

旋转按基座固定轴合成，IK 从上一成功下发的关节目标起算。只有 SDK 成功且控制代次、参考版本均有效，才提交实际航点对应的参考。松 LB、回中、急停和模式切换后，旧参考不带入新一轮操作。默认50 Hz入口使用下文的连续夹爪参考。

现用摇杆参数（2026-09-21 用户测试反馈正常）：50 Hz，XYZ每轴每周期最多2.5mm，合成旋转每周期最多0.5°，夹爪参考速度最多120 mm/s；单关节目标与反馈最大差值 10°，夹爪目标 0～120 mm、目标与反馈最大差值 15 mm。

## 回放

现有 replay CLI 可设置 `trajectory={time_scale, control_hz, hold_settings}` 和独立 `trajectory_report_path`。离线以 PCHIP 生成七维连续参考，关节和夹爪使用同一时间进度。每个实际 float32 目标都检查限位、步长和工具间隙。

PCHIP 不超出相邻来源值的各分量范围，具有连续速度，但不保证连续加速度；仍是离散工具点校验，不宣称扫掠碰撞验证。初次对照采用 `time_scale=1.25`、20 Hz。夹爪来源 action 必须非负，插值结果继续使用明确的 `max(0,g)` 闭合规则。

执行记录保存真实目标、来源时间与来源区间，不声称每个原始动作都被单独原样下发。等待跟随时检查反馈和 watchdog，不重复发送上一目标，也不跳过生成的参考。

操作者先到轨迹起点，输入 `start` 才启动。运行中 `stop` 或 `quit` 固定保持关节、保留夹爪指令；Ctrl+C 和故障沿用电子急停，可能下沉。退出不自动失能、复位或回零。

## 数据语义

原始观测和示教转换 action 不改写。摇杆录制仍保存实际下发的七维动作；参考状态通过进程内元数据传递，不增加策略维度。回放插值只产生独立执行参考，不反向覆盖 Dataset。现场平顺性及夹持时序需另行验证。

## 50 Hz 默认连续夹爪（2026-09-20）

在 teleop 配置设置 `gripper_reference`：`period_s=0.02`、`max_speed_m_s=0.12`、`acceleration_m_s2=1.2`、`max_lead_m=0.008`。周期必须匹配 control_hz，领先量不得超过现有执行步长限制。普通 `piper record` 已启用上述设置；不再使用20 Hz采集入口。历史配置缺省时仍按其原有增量语义读取，不改写历史数据。

LT/RT 表示速度意图。参考从最近成功下发目标按时间推进，不能每周期重新从反馈加增量。参考加速至上限约需 0.1 秒；实际夹爪速度仍取决于执行器、负载和反馈。到边界或领先量受限时停止积累，延迟周期不追赶。松开扳机停止推进但保留目标及夹持力，夹爪可能继续到达已下发目标；反向时清除旧方向参考速度。LB、模式、故障和控制代次使旧参考失效。七维动作仍记录真实下发目标。

准备阶段 A/Y 的上游通用慢周期警告只保留在会话日志，不刷控制台；同一周期的其他异常及录制中的慢周期警告仍显示。A/Y 轨迹和完整路径检查不变。

固定入口：`piper record`。使用640×480 RGBD60、控制与Dataset 50 Hz，默认20次尝试。已有试验会话仍不计入正式ACT示范，不与历史20 Hz回合自动混合。
